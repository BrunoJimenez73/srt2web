Plan de Mejoras y Evolución - SRT2Web

Este documento detalla la visión a corto y medio plazo para el proyecto, centrándose en la estabilidad, el rendimiento y la experiencia de usuario.

Corto Plazo: Estabilidad y UX

Frontend & UX

  • Implementación de Responsive Design completo para tablets y móviles.
  • Añadir Atajos de Teclado para control rápido del pipeline.
  • Mejorar la visualización de logs con colores por severidad y filtros avanzados.
  • Implementar un sistema de notificaciones (Toasts) más robusto para errores críticos.

Core & Pipeline

  • Expandir la suite de tests a tests e2e simulando streams SRT reales.
  • Optimizar el FFmpegPool para reducir el consumo de memoria en reposo.
  • Mejorar la detección automática de hardware (GPU/MPS) al inicio.
  • Añadir validaciones más estrictas al config.yaml para evitar crashes por sintaxis.

Medio Plazo: Funcionalidades Avanzadas

Procesamiento de Audio/Video

  • Soporte para múltiples idiomas de traducción simultáneos (Multi-track).
  • Implementar estilos personalizados de subtítulos (fuente, color, posición) vía UI.
  • Integrar más motores de TTS además de Piper (ej. Coqui TTS o APIs cloud).
  • Añadir la capacidad de grabar el stream procesado en disco localmente.

Infraestructura

  • Refactorizar los módulos a un sistema de Plugins dinámicos.
  • Implementar un sistema de Hot-Reload para la configuración sin reiniciar el servidor.
  • Crear un dashboard de métricas históricas (CPU/GPU/Latencia) usando una base de datos ligera.
  • Soporte nativo para Docker Compose con despliegue simplificado.

Visión a Largo Plazo

Convertir SRT2Web en el estándar de traducción en tiempo real para streaming, permitiendo la integración de modelos de IA locales masivos (LLMs) para resúmenes en vivo y moderación de contenido automática.
