REST API

Referencia completa de los endpoints REST del servidor SRT2Web.

Base URL

http://localhost:9999/api

Pipeline Control

GET /api/status

Obtiene el estado completo del pipeline incluyendo modulos, input, output y metricas del sistema.

POST /api/start

Inicia el pipeline de procesamiento. Si ya esta corriendo, devuelve un error.

POST /api/stop

Detiene el pipeline y limpia archivos temporales.

POST /api/restart

Reinicia el pipeline con la configuracion actual.

Configuracion

GET /api/config

Obtiene la configuracion actual completa del sistema.

PUT /api/config

Actualiza parcialmente la configuracion. Los valores no especificados mantienen su estado actual.

Modulos

GET /api/modules

Lista todos los modulos registrados con su estado actual.

PUT /api/modules/:name/toggle

Habilita o deshabilita un modulo especifico. Soporta hot-reload sin reiniciar el pipeline.

ParametroTipoDescripcion
namestringNombre del modulo (ej: transcriber, translator)

GET /api/modules/:name/debug

Obtiene informacion de debug del modulo (estado interno, metricas, errores).

ParametroTipoDescripcion
namestringNombre del modulo

Info

GET /api/input-info

Informacion de la fuente de entrada.

GET /api/output-info

Informacion del output HLS.

GET /api/health

Health check para monitoreo y load balancers.

Codigos de Error

CodigoMensajeDescripcion
400Bad RequestParametros invalidos o body malformado
404Not FoundModulo o endpoint no encontrado
409ConflictPipeline ya esta corriendo/detenido
422Unprocessable EntityConfiguracion invalida
500Internal Server ErrorError interno del servidor

Ejemplos de Uso

cURL

# Iniciar pipeline
curl -X POST http://localhost:9999/api/start
# Obtener estado
curl http://localhost:9999/api/status
# Actualizar config
curl -X PUT http://localhost:9999/api/config -H Content-Type:application/json -d modules-transcriber-model-base
# Toggle modulo
curl -X PUT http://localhost:9999/api/modules/translator/toggle

JavaScript

// Iniciar pipeline
fetch(http://localhost:9999/api/start, {method: POST})
// Obtener estado
fetch(http://localhost:9999/api/status)
// Toggle modulo
fetch(http://localhost:9999/api/modules/translator/toggle, {method: PUT})
