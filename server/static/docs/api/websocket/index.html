WebSocket API

Conexión bidireccional para logs en tiempo real y comandos interactivos.

Conexión

JavaScript
const ws = new WebSocket('ws://localhost:9999/ws/logs');

ws.onopen = () => {
  console.log('WebSocket connected');
};

ws.onmessage = (event) => {
  const data = JSON.parse(event.data);
  console.log(data);
};

ws.onclose = () => {
  console.log('WebSocket disconnected');
};

Mensajes del Servidor

El servidor envía mensajes JSON con la siguiente estructura:

Log Message

JSON
{
  "type": "log",
  "level": "INFO",
  "message": "Processing chunk 42",
  "timestamp": "2026-03-21T10:30:00.000Z",
  "module": "transcriber"
}

Status Update

JSON
{
  "type": "status",
  "pipeline_state": "RUNNING",
  "modules": {
    "transcriber": { "state": "RUNNING" },
    "translator": { "state": "DISABLED" }
  },
  "chunks_processed": 42
}

Metric Update

JSON
{
  "type": "metric",
  "name": "process_time",
  "module": "transcriber",
  "value": 1200,
  "timestamp": "2026-03-21T10:30:00.000Z"
}

Error Message

JSON
{
  "type": "error",
  "module": "transcriber",
  "message": "Whisper model failed to load",
  "details": "CUDA out of memory",
  "timestamp": "2026-03-21T10:30:00.000Z"
}

Comandos del Cliente

Puedes enviar comandos al servidor para solicitar información:

Get Status

Enviar
{
  "command": "get_status"
}

Ping (Heartbeat)

Enviar
{
  "command": "ping"
}

Respuesta del servidor:

Respuesta
{
  "type": "pong",
  "latency_ms": 5
}

Ejemplo Completo

Client completo
class WSClient {
  constructor(url) {
    this.url = url;
    this.ws = null;
    this.reconnectDelay = 1000;
    this.maxDelay = 30000;
  }

  connect() {
    this.ws = new WebSocket(this.url);

    this.ws.onopen = () => {
      console.log('Connected');
      this.reconnectDelay = 1000;
    };

    this.ws.onmessage = (event) => {
      const data = JSON.parse(event.data);
      this.handleMessage(data);
    };

    this.ws.onclose = () => {
      console.log('Disconnected, reconnecting...');
      setTimeout(() => this.connect(), this.reconnectDelay);
      this.reconnectDelay = Math.min(this.reconnectDelay * 2, this.maxDelay);
    };

    this.ws.onerror = (error) => {
      console.error('WebSocket error:', error);
    };
  }

  handleMessage(data) {
    switch (data.type) {
      case 'log':
        console.log(`[${data.level}] ${data.module}: ${data.message}`);
        break;
      case 'status':
        this.updateStatus(data);
        break;
      case 'metric':
        this.updateMetric(data);
        break;
      case 'error':
        this.handleError(data);
        break;
      case 'pong':
        console.log(`Latency: ${data.latency_ms}ms`);
        break;
    }
  }

  sendCommand(command) {
    if (this.ws?.readyState === WebSocket.OPEN) {
      this.ws.send(JSON.stringify(command));
    }
  }

  ping() {
    this.sendCommand({ command: 'ping' });
  }

  getStatus() {
    this.sendCommand({ command: 'get_status' });
  }

  updateStatus(data) { /* update UI */ }
  updateMetric(data) { /* update charts */ }
  handleError(data) { /* show error */ }
}

const client = new WSClient('ws://localhost:9999/ws/logs');
client.connect();

// Heartbeat cada 30 segundos
setInterval(() => client.ping(), 30000);
Auto-reconnect: El cliente WebSocket del dashboard implementa reconexión automática con exponential backoff (1s → 2s → 4s → ... hasta 30s máximo).
