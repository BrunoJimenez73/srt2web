Arquitectura del Frontend

SRT2Web usa Astro como framework frontal con TypeScript y Tailwind CSS. La interfaz de usuario se sirve como archivos estaticos desde el servidor FastAPI.

Tecnologias

  • Astro 5.0: Generador de sitios estaticos con arquitectura Islands
  • TypeScript: Tipado estatico para JavaScript
  • Tailwind CSS 4.0: Framework de utilidades CSS
  • hls.js: Reproductor HLS para el navegador

Estructura del Frontend

Estructura
frontend/src/
├── components/          # Componentes .astro reutilizables
│   ├── ui/            # Componentes base (Button, Input, Card)
│   └── layout/        # Componentes de layout (Header)
├── layouts/            # Layouts de pagina
│   └── BaseLayout.astro
├── lib/               # Modulos JavaScript/TypeScript
│   ├── api.ts         # FuncionesCliente de API
│   ├── dashboard.ts   # Script principal del dashboard
│   ├── types.ts      # Definiciones de tipos
│   ├── constants.ts   # Constantes centralizadas
│   ├── i18n.ts        # Sistema de traduccion
│   └── modules/       # Modulos de charakteristicas
├── pages/             # Paginas (rutas)
│   ├── index.astro   # Dashboard principal
│   ├── player.astro # Reproductor HLS
│   └── docs/        # Documentacion
└── styles/
    └── globals.css  # Estilos globales (Tailwind)

Comandos de Desarrollo

  • npm run dev - Servidor de desarrollo
  • npm run build:local - Compilar para produccion

Integracion con el Backend

El frontend se comunica con FastAPI mediante HTTP y WebSocket:

API Client
// Configurado en frontend/src/lib/constants.ts
import { SERVER_PORT, API_ENDPOINTS, WS_PATHS } from '../lib/constants';

// Frontend to Backend (HTTP)
const res = await fetch('http://localhost:' + SERVER_PORT + API_ENDPOINTS.STATUS);
const status = await res.json();

// Frontend to Backend (WebSocket)
const ws = new WebSocket('ws://localhost:' + SERVER_PORT + WS_PATHS.LOGS);
ws.onmessage = (e) => console.log(JSON.parse(e.data));

Build y Deployment

Despues de compilar, los archivos estaticos se copian a server/static/:

Build
npm run build:local
cp -r frontend/dist/* server/static/
