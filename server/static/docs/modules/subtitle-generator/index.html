Subtitle Generator

Generación de subtítulos en formato WebVTT y SRT para reproductores HLS.

Descripción

El módulo Subtitle Generator crea subtítulos a partir del texto transcrito (y traducido opcionalmente). Genera subtítulos WebVTT para HLS en tiempo real y archivos SRT por chunk para descarga.

Configuración

Path Type Default Description
modules.subtitle_generator.enabled boolean false Habilitar generación de subtítulos.
modules.subtitle_generator.format string webvtt Formato: webvtt o srt.
modules.subtitle_generator.use_translated boolean false Usar texto traducido en lugar del original.
modules.subtitle_generator.audio_offset_ms integer 0 Offset de tiempo en ms para sincronización.
modules.subtitle_generator.font_size integer 48 Tamaño de fuente para subtítulos.

Dependencias

Habilita automáticamente:

Ninguno — es módulo terminal en la cadena de subtítulos.

Requiere que esté habilitado:

translator — consume la traducción

Ejemplos

WebVTT con Texto Traducido

config.yaml
modules:
  subtitle_generator:
    enabled: true
    format: webvtt
    use_translated: true  # subtítulos en el idioma destino

WebVTT con Texto Original

config.yaml
modules:
  subtitle_generator:
    enabled: true
    format: webvtt
    use_translated: false  # subtítulos en idioma original

Métricas

MétricaDescripción
process_timeTiempo de generación (ms)
chunks_processedTotal de chunks procesados

Salida

PipelineData
{
    "subtitles_path": "./output/hls/subs.vtt",
    "metadata": {
        "format": "webvtt",
        "use_translated": true,
        "chunks_included": 15
    }
}
