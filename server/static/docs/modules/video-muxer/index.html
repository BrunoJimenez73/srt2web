Video Muxer

Empaquetado final del stream HLS con subtítulos integrados y audio mezclado.

Descripción

El módulo Video Muxer es el último eslabón del pipeline. Recibe video, audio mezclado y subtítulos, y los empaqueta en un stream HLS compatible con HLS.js y reproductores nativos.

Configuración

Path Type Default Description
modules.video_muxer.enabled boolean true Habilitar salida HLS.
modules.video_muxer.hls_segment_duration integer 6 Duración de segmentos HLS en segundos.
modules.video_muxer.hls_list_size integer 6 Número de segmentos en la playlist.
modules.video_muxer.encoder_mode string copy Modo: copy (reempaquetar) o encode (re-encoder).
modules.video_muxer.video_crf integer 23 CRF para re-encoding (0-51).
modules.video_muxer.audio_codec string aac Codec de audio: aac o mp3.
modules.video_muxer.audio_bitrate string 128k Bitrate de audio.
modules.video_muxer.output_path string ./output/hls Ruta de salida.

Modos de Encoding

ModoDescripciónUso
copyReempaqueta sin recodificarMínimo delay, máxima velocidad
encodeRecodifica videoMejor compresión, control CRF
Modo copy: Recomendado para streams en vivo. El video se reempaqueta sin recodificar, minimizando el delay. Requiere que el stream source use h264/aac.

Dependencias

Habilita automáticamente:

Ninguno — es módulo terminal.

Requiere que esté habilitado:

Ninguno — es el último módulo de la cadena.

Ejemplos

Mínimo Delay (Reempaquetar)

config.yaml
modules:
  video_muxer:
    enabled: true
    encoder_mode: copy
    hls_segment_duration: 2
    hls_list_size: 4

Alta Calidad (Recodificar)

config.yaml
modules:
  video_muxer:
    enabled: true
    encoder_mode: encode
    video_crf: 20       # menor = mejor calidad
    audio_codec: aac
    audio_bitrate: 192k
    hls_segment_duration: 6
    hls_list_size: 6

NVIDIA NVENC

config.yaml
modules:
  video_muxer:
    enabled: true
    encoder_mode: encode
    encoder_mode: nvenc  # descomentar si hay GPU NVIDIA
    video_crf: 23
    audio_codec: aac
    audio_bitrate: 128k

Métricas

MétricaDescripción
process_timeTiempo de muxing (ms)
memory_usageMemoria del proceso FFmpeg
chunks_processedTotal de chunks empaquetados
output_size_mbTamaño total de salida (MB)

Salida

El módulo produce los siguientes archivos en ./output/hls/:

Estructura de salida
output/hls/
├── stream.m3u8          # Playlist HLS principal
├── seg_000.ts          # Segmentos de video/audio
├── seg_001.ts
├── seg_002.ts
├── subs.vtt            # Subtítulos WebVTT
└── chunk_001.srt       # Subtítulos SRT por chunk

Playlist HLS

stream.m3u8
#EXTM3U
#EXT-X-VERSION:3
#EXT-X-TARGETDURATION:6
#EXT-X-MEDIA-SEQUENCE:0
#EXTINF:6.0,
seg_000.ts
#EXTINF:6.0,
seg_001.ts
#EXTINF:6.0,
seg_002.ts
#EXT-X-ENDLIST
Listo para streaming: El stream HLS está disponible en http://localhost:9999/stream/stream.m3u8 y puede reproducirse en cualquier reproductor HLS.
