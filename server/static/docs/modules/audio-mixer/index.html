Audio Mixer

Mezcla audio original (con ducking) y audio TTS doblado usando FFmpeg.

Descripción

El módulo Audio Mixer combina el audio original del stream con el audio TTS generado. El audio original se reduce de volumen (ducking) automáticamente para dar prioridad a la voz doblada.

Configuración

Path Type Default Description
modules.audio_mixer.enabled boolean false Habilitar mezcla de audio.
modules.audio_mixer.original_volume float 0.4 Volumen del audio original (0.0 - 2.0).
modules.audio_mixer.dubbed_volume float 1.1 Volumen del audio doblado (0.0 - 2.0).
modules.audio_mixer.tts_volume float 1.0 Volumen del audio TTS (0.0 - 2.0).

Dependencias

Habilita automáticamente:

Ninguno — es módulo terminal.

Requiere que esté habilitado:

translator y tts_engine

Orden de volumen: dubbed_volume debe ser mayor que original_volume para que el doblaje sea claramente audible.

Ejemplos

Doblaje Balanceado

config.yaml
modules:
  audio_mixer:
    enabled: true
    original_volume: 0.3   # audio original reducido
    dubbed_volume: 1.0      # doblaje a volumen normal
    tts_volume: 1.0

Mezcla Equilibrada

config.yaml
modules:
  audio_mixer:
    enabled: true
    original_volume: 0.5   # 50% del original
    dubbed_volume: 0.8    # 80% del doblaje
    tts_volume: 1.0
