TTS Engine

Síntesis de voz natural usando Microsoft Edge TTS para doblaje automático.

Descripción

El módulo TTS Engine convierte el texto traducido a audio usando Edge-TTS (Microsoft), que ofrece voces neuronales de alta calidad sin costo. El audio generado puede mezclarse con el audio original para crear una experiencia de doblaje.

Configuración

Path Type Default Description
modules.tts_engine.enabled boolean false Habilitar síntesis de voz.
modules.tts_engine.voice string es-ES-AlvaroNeural Voz Edge-TTS a usar.
modules.tts_engine.speed float 1.0 Velocidad del habla (0.5 - 2.0).

Otros Idiomas

Edge-TTS soporta más de 140 voces en más de 50 idiomas. Puedes listar todas las voces disponibles:

Listar voces
import edge_tts
import asyncio

async def list_voices():
    voices = await edge_tts.list_voices()
    for v in voices:
        print(f"{v['ShortName']} - {v['Locale']} - {v['Gender']}")

asyncio.run(list_voices())

Dependencias

Habilita automáticamente:

audio_mixer — necesita TTS para mezclar

Requiere que esté habilitado:

translator — consume el texto traducido

TTS Engine requiere que translator esté habilitado. Si el traductor está deshabilitado, TTS también se deshabilitará.

Ejemplos

Básico — Español Masculino

config.yaml
modules:
  tts_engine:
    enabled: true
    voice: es-ES-AlvaroNeural
    speed: 1.0

Español Mexicano

config.yaml
modules:
  tts_engine:
    enabled: true
    voice: es-MX-DaliaNeural
    speed: 0.95  # ligeramente más lento para claridad

Inglés Británico con Velocidad Ajustada

config.yaml
modules:
  transcriber:
    language: auto
  translator:
    enabled: true
    source_lang: auto
    target_lang: en
  tts_engine:
    enabled: true
    voice: en-GB-SoniaNeural
    speed: 1.05

Salida

El módulo produce los siguientes campos en PipelineData:

PipelineData
{
    "dubbed_audio_path": "./output/temp_tts/chunk_001.wav",
    "metadata": {
        "voice": "es-ES-AlvaroNeural",
        "speed": 1.0,
        "audio_duration": 5.8,
        "text_length": 125
    }
}
Sincronización: El módulo sincroniza automáticamente el audio TTS con el chunk usando padding de silencio cuando es necesario.
