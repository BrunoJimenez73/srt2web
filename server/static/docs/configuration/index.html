Referencia de Configuración

Referencia completa de todas las opciones disponibles en config.yaml.

Estructura General

config.yaml (completo)
server:
  host: "0.0.0.0"
  port: 9999
  cors_origins: ["*"]
  auth_token: ""

input:
  type: srt  # srt | file | rtmp
  srt:
    listen_port: 9000
    mode: listener
    latency_ms: 1000
    caller_address: ""
    chunk_duration_sec: 6
  file:
    path: ""
    loop: false
    speed: 1.0
  rtmp:
    url: ""
    mode: listener

pipeline:
  chunk_duration_sec: 6

modules:
  audio_extractor:
    enabled: true
  transcriber:
    enabled: true
    model: tiny
    language: auto
    device: auto
  translator:
    enabled: false
    source_lang: en
    target_lang: es
  subtitle_generator:
    enabled: false
    format: webvtt
    use_translated: false
    audio_offset_ms: 0
    font_size: 48
  tts_engine:
    enabled: false
    voice: es-ES-AlvaroNeural
    speed: 1.0
  audio_mixer:
    enabled: false
    original_volume: 0.4
    dubbed_volume: 1.1
    tts_volume: 1.0
  video_muxer:
    enabled: true
    hls_segment_duration: 6
    hls_list_size: 6
    encoder_mode: copy
    video_crf: 23
    audio_codec: aac
    audio_bitrate: 128k
    output_path: ./output/hls

output_dir:
  directory: ./output

Server

Path Type Default Description
server.host string 0.0.0.0 Host del servidor web.
server.port integer 9999 Puerto TCP del servidor FastAPI.
server.cors_origins array [*] Orígenes permitidos para CORS.
server.auth_token string '' Token para autenticación (vacío = deshabilitado).

Input

General

Path Type Default Description
input.type required string srt Tipo de entrada: srt, file, o rtmp.

SRT Input

Path Type Default Description
input.srt.listen_port required integer 9000 Puerto UDP para escuchar conexiones SRT entrantes.
input.srt.mode required string listener Modo SRT: listener o caller.
input.srt.latency_ms integer 1000 Latencia SRT en milisegundos. Recomendado: 1000-4000ms.
input.srt.caller_address string '' Dirección del caller (para modo caller).
input.srt.chunk_duration_sec float 6 Duración de cada fragmento en segundos.

File Input

Path Type Default Description
input.file.path string '' Ruta al archivo de video de entrada.
input.file.loop boolean false Reproducir en bucle.
input.file.speed float 1.0 Velocidad de reproducción (1.0 = normal).

RTMP Input

Path Type Default Description
input.rtmp.url string '' URL RTMP (ej: rtmp://localhost/live/stream).
input.rtmp.mode string listener Modo: listener o caller.

Pipeline

Path Type Default Description
pipeline.chunk_duration_sec float 6 Duración de chunks en segundos. Debe coincidir con input.srt.chunk_duration_sec.

Modules

Transcriber

Path Type Default Description
modules.transcriber.enabled boolean true Habilitar/deshabilitar transcripción.
modules.transcriber.model string tiny Modelo Whisper: tiny, base, small, medium, large-v3, large-v3-turbo.
modules.transcriber.language string auto Idioma del audio. auto = detección automática.
modules.transcriber.device string auto Dispositivo: auto, cpu, cuda, mps.
Modelos Whisper: tiny (~75MB), base (~148MB), small (~488MB), medium (~1.5GB), large-v3 (~2.9GB), large-v3-turbo (~1.6GB). Modelos más grandes ofrecen mejor precisión pero requieren más VRAM.

Translator

Path Type Default Description
modules.translator.enabled boolean false Habilitar traducción.
modules.translator.source_lang string en Idioma source (código ISO 639-1).
modules.translator.target_lang string es Idioma destino (código ISO 639-1).

Subtitle Generator

Path Type Default Description
modules.subtitle_generator.enabled boolean false Habilitar generación de subtítulos.
modules.subtitle_generator.format string webvtt Formato: webvtt o srt.
modules.subtitle_generator.use_translated boolean false Usar texto traducido en lugar del original.
modules.subtitle_generator.audio_offset_ms integer 0 Offset de tiempo en ms para sincronización.
modules.subtitle_generator.font_size integer 48 Tamaño de fuente para subtítulos.

TTS Engine

Path Type Default Description
modules.tts_engine.enabled boolean false Habilitar síntesis de voz.
modules.tts_engine.voice string es-ES-AlvaroNeural Voz Edge-TTS (ej: es-ES-AlvaroNeural, es-MX-DaliaNeural).
modules.tts_engine.speed float 1.0 Velocidad del habla (0.5 = lento, 2.0 = rápido).

Audio Mixer

Path Type Default Description
modules.audio_mixer.enabled boolean false Habilitar mezcla de audio.
modules.audio_mixer.original_volume float 0.4 Volumen del audio original (0.0 - 2.0).
modules.audio_mixer.dubbed_volume float 1.1 Volumen del audio doblado (0.0 - 2.0).
modules.audio_mixer.tts_volume float 1.0 Volumen del audio TTS (0.0 - 2.0).

Video Muxer

Path Type Default Description
modules.video_muxer.enabled boolean true Habilitar salida HLS.
modules.video_muxer.hls_segment_duration integer 6 Duración de segmentos HLS en segundos.
modules.video_muxer.hls_list_size integer 6 Número de segmentos en la playlist.
modules.video_muxer.encoder_mode string copy Modo de codificación: copy (reempaquetar) o encode (re-encoder).
modules.video_muxer.video_crf integer 23 CRF de video para re-encoding (0-51, menor = mejor calidad).
modules.video_muxer.audio_codec string aac Codec de audio: aac o mp3.
modules.video_muxer.audio_bitrate string 128k Bitrate de audio (ej: 128k, 192k, 256k).
modules.video_muxer.output_path string ./output/hls Ruta de salida para archivos HLS.

Output Directory

Path Type Default Description
output_dir.directory string ./output Directorio base para todos los archivos de salida.

Ejemplos de Configuración

Básico — Solo Transcripción

Transcripción simple
server:
  port: 9999

input:
  type: srt
  srt:
    listen_port: 9000
    mode: listener

modules:
  transcriber:
    enabled: true
    model: base
    language: auto

Completo — Traducción + TTS + Mezcla

Pipeline completo

  port: 9999

input:
  type: srt
  srt:
    listen_port: 9000
    chunk_duration_sec: 10

modules:
  transcriber:
    enabled: true
    model: small
    language: auto
    device: cuda

  translator:
    enabled: true
    source_lang: en
    target_lang: es

    enabled: true

    enabled: true

    enabled: true
    original_volume: 0.3
    dubbed_volume: 1.0

  video_muxer:
    enabled: true
    hls_segment_duration: 10
    encoder_mode: copy
