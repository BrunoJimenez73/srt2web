Instalación

Guía completa de instalación de SRT2Web. Requisitos del sistema, dependencias y primeros pasos.

Requisitos del Sistema

Componente Mínimo Recomendado Notas
CPU 4 cores 8+ cores Más cores = mejor paralelismo en módulos
RAM 8 GB 16+ GB Whisper large requiere ~4GB adicional
GPU NVIDIA 4GB VRAM NVIDIA 8GB+ VRAM NVENC para encoding, CUDA para Whisper
OS Windows 10+ Windows 11 / Ubuntu 22.04+ Linux con mejor soporte de procesos FFmpeg
Python 3.10+ 3.11+ —

Dependencias Externas

FFmpeg

FFmpeg es requerido para el procesamiento de video y audio. Asegúrate de que esté en el PATH del sistema.

# Windows (con winget)
winget install ffmpeg

# Windows (con Chocolatey)
choco install ffmpeg

# Ubuntu/Debian
sudo apt install ffmpeg

# Verificar instalación
ffmpeg -version

Instalación del Proyecto

  1. 1

    Clonar el Repositorio

    git clone https://github.com/tu-usuario/srt2web.git
cd srt2web
  2. 2

    Crear Entorno Virtual

    # Crear y activar entorno virtual
python -m venv venv

# Windows
venv\Scripts\activate

# Linux/macOS
source venv/bin/activate
  3. 3

    Instalar Dependencias

    pip install -r requirements.txt

    Esto instalará: FastAPI, uvicorn, faster-whisper, argostranslate, edge-tts, ffmpeg-python, uvicorn, psutil, gputil, pyyaml, numpy, torch.

  4. 4

    Configuración Inicial

    Edita config.yaml con los valores deseados:

    config.yaml
    server:
  host: 0.0.0.0
  port: 9999

input:
  type: srt
  srt:
    listen_port: 9000
    mode: listener
    latency_ms: 1000
    chunk_duration_sec: 6

modules:
  transcriber:
    enabled: true
    model: tiny
    language: auto
    device: auto

  translator:
    enabled: false
    source_lang: en
    target_lang: es
  5. 5

    Construir el Frontend (Opcional)

    Si quieres usar el dashboard web, construye el frontend Astro:

    cd frontend
npm install
npm run build
  6. 6

    Iniciar el Servidor

    python main.py

    El servidor estará disponible en:

    • Dashboard: http://localhost:9999
    • Player: http://localhost:9999/player
    • API: http://localhost:9999/docs

Verificación

Verifica que el sistema esté correctamente instalado:

# Verificar versión de Python
python --version

# Verificar FFmpeg
ffmpeg -version | head -1

# Verificar GPU (NVIDIA)
nvidia-smi

# Verificar que el servidor inicia
python main.py --help

Docker (Alternativo)

También puedes ejecutar SRT2Web con Docker:

Dockerfile
FROM python:3.11-slim

RUN apt-get update && apt-get install -y ffmpeg git

WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY . .
EXPOSE 9999 9000/udp

CMD ["python", "main.py"]
ℹ
GPU en Docker: Para usar GPU en Docker, necesitas --gpus all y los drivers de NVIDIA instalados en el host.
