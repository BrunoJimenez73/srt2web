Troubleshooting

FAQ y soluciones a problemas comunes con SRT2Web.

Instalación

⚠ Error: No module named 'faster_whisper'

Solución:

pip install faster-whisper

Si tienes problemas con PyTorch, intenta:

pip install torch torchaudio --index-url https://download.pytorch.org/whl/cpu
⚠ Error: FFmpeg not found

Solución:

Instala FFmpeg y asegúrate de que esté en el PATH del sistema:

# Windows (winget)
winget install ffmpeg

# Verificar
ffmpeg -version

Reinicia tu terminal después de instalar.

⚠ CUDA out of memory al cargar Whisper

Solución: Usa un modelo más pequeño o cambia a CPU:

config.yaml
modules:
  transcriber:
    model: tiny  # o base
    device: cpu  # usa CPU en lugar de GPU

O limpia la caché de PyTorch:

import torch
torch.cuda.empty_cache()

Conexión SRT

⚠ No se reciben datos SRT — INPUT permanece gris

Posibles causas y soluciones:

  1. Firewall: Verifica que el puerto 9000 (UDP) esté abierto
  2. Dirección incorrecta: Usa srt://127.0.0.1:9000 para local
  3. Modo SRT: Asegúrate de que el encoder use modo listener
  4. URL de OBS: Verifica que la URL sea srt://localhost:9000?mode=listener
# Verificar que el puerto está escuchando (Windows)
netstat -an | findstr 9000
⚠ Stream entrecortado o con lags

Solución: Aumenta la latencia SRT:

config.yaml
input:
  srt:
    latency_ms: 2000  # aumenta de 1000 a 2000 o más

También verifica tu ancho de banda — asegúrate de que el bitrate de OBS no supere tu conexión.

Transcripción y Traducción

⚠ Transcripción vacía o con errores

Posibles causas:

  1. Sin audio: Verifica que el stream tenga audio
  2. Idioma incorrecto: Especifica el idioma manualmente
  3. Audio muy corto: Aumenta chunk_duration_sec a 10
config.yaml
modules:
  transcriber:
    language: es  # especifica el idioma directamente
⚠ Traducción de mala calidad

Argos Translate usa modelos más pequeños que Google Translate. Para mejor calidad:

  1. Usa source_lang: auto para detección correcta
  2. Simplifica el discurso — jerga y modismos son difíciles de traducir
  3. Aumenta el chunk duration para más contexto

TTS y Audio

⚠ Audio TTS desincronizado con video

Solución: Ajusta el offset de sincronización:

config.yaml
modules:
  subtitle_generator:
    audio_offset_ms: -500  # valor negativo adelanta, positivo atrasa

Prueba valores entre -1000ms y +1000ms hasta que esté sincronizado.

⚠ Error de voz Edge-TTS no disponible

Solución: Usa una voz válida. Verifica las voces disponibles:

import edge_tts
import asyncio

async def list():
    voices = await edge_tts.list_voices()
    for v in voices:
        if 'es' in v['Locale']:
            print(v['ShortName'])

asyncio.run(list())

Voces conocidas que funcionan: es-ES-AlvaroNeural, es-ES-ElviraNeural

HLS y Streaming

⚠ Player no carga el stream — 404
  1. Verifica que el pipeline esté corriendo (dashboard verde)
  2. Revisa que haya chunks procesados
  3. Abre directamente: http://localhost:9999/stream/stream.m3u8
⚠ Subtítulos no aparecen en el player

Verifica que los subtítulos estén habilitados:

config.yaml
modules:
  subtitle_generator:
    enabled: true

En el player, asegúrate de que CC/Subtitles esté activado.

Dashboard y API

⚠ WebSocket no conecta — panel de logs vacío
  1. Verifica que el servidor esté corriendo
  2. Abre las herramientas de desarrollo del navegador (F12) → Console
  3. Revisa errores de CORS si accedes desde otra máquina
config.yaml
server:
  cors_origins: ["http://localhost:9999"]  # especifica orígenes
⚠ Configuración no se guarda

Los cambios desde el dashboard son en tiempo real pero no persisten al reiniciar. Para guardar permanentemente:

  1. Edita config.yaml manualmente
  2. O reinicia el servidor después de hacer cambios desde el dashboard

Logs

Para obtener logs detallados:

# Ejecutar con logging verbose
python main.py --log-level DEBUG

# Ver logs en tiempo real
tail -f server.out

Obtener Ayuda

Si el problema persiste:

  • Revisa los logs completos del servidor
  • Incluye el output de python main.py --log-level DEBUG
  • Reporta el issue en GitHub con la información de tu sistema (OS, Python, GPU)
Tip: La mayoría de los problemas se resuelven reiniciando el servidor y limpiando los archivos temporales en output/.
