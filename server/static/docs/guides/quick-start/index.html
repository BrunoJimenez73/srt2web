Quick Start

Configura y ejecuta tu primer stream con SRT2Web en 5 minutos.

Arquitectura de Conexión

graph LR OBS["OBS Studio<br/>(Encoder)"] SRT["srt://localhost:9000"] S2W["SRT2Web<br/>Pipeline"] HLS["http://localhost:9999<br/>/stream/stream.m3u8"] PLAYER["Player<br/>(HLS.js)"] OBS -->|"SRT Stream"| SRT SRT --> S2W S2W -->|"HLS"| HLS HLS --> PLAYER

Requisitos Previos

  1. OBS Studio instalado (obsproject.com)
  2. FFmpeg instalado y en PATH
  3. Python 3.10+ con pip install -r requirements.txt

Pasos

  1. 1

    Iniciar el Servidor

    python main.py

    Verás algo como:

    INFO:     Uvicorn running on http://0.0.0.0:9999
INFO:     Application startup complete.
INFO:     Pipeline state: IDLE
  2. 2

    Abrir el Dashboard

    Abre en tu navegador:

    http://localhost:9999

    Verás el dashboard con todos los módulos y métricas.

  3. 3

    Configurar OBS Studio

    En OBS:

    1. Añade una fuente de video (captura de pantalla, webcam, etc.)
    2. Ve a File → Settings → Stream
    3. Selecciona Custom como servicio
    4. En servidor pon: srt://localhost:9000?mode=listener
    5. Deja el campo Stream Key vacío
    Si OBS no soporta SRT directamente, usa el plugin SRT Encoder para OBS.
  4. 4

    Iniciar el Pipeline

    En el dashboard, haz clic en el botón INICIAR o usa:

    curl -X POST http://localhost:9999/api/start

    El indicador INPUT se pondrá verde cuando reciba datos de SRT.

  5. 5

    Iniciar Stream en OBS

    En OBS, haz clic en Start Streaming. Verás los indicadores de módulos iluminándose en verde mientras procesa chunks.

  6. 6

    Ver el Stream

    Abre el reproductor en:

    http://localhost:9999/player

    O directamente con HLS:

    http://localhost:9999/stream/stream.m3u8

Configuración Mínima

Para empezar, esta es la configuración más simple:

config.yaml (mínimo)
server:
  port: 9999

input:
  type: srt
  srt:
    listen_port: 9000
    chunk_duration_sec: 6

modules:
  transcriber:
    enabled: true
    model: tiny
    device: cpu

Con Traducción y TTS

Para doblaje automático (inglés → español):

config.yaml (doblaje)
modules:
  transcriber:
    enabled: true
    model: base
    language: auto

  translator:
    enabled: true
    source_lang: en
    target_lang: es

  tts_engine:
    enabled: true
    voice: es-ES-AlvaroNeural

  audio_mixer:
    enabled: true
    original_volume: 0.3
    dubbed_volume: 1.0

  subtitle_generator:
    enabled: true
    format: webvtt
    use_translated: true

Solución de Problemas

⚠ No recibo datos SRT
  • Verifica que OBS esté enviando a srt://localhost:9000
  • Revisa los logs de OBS para errores
  • Asegúrate de que el firewall permita UDP en puerto 9000
⚠ Pipeline no inicia
  • Verifica que FFmpeg esté instalado: ffmpeg -version
  • Revisa que el puerto 9999 no esté en uso
  • Revisa los logs del servidor para errores específicos
⚠ Subtítulos desincronizados
  • Ajusta modules.subtitle_generator.audio_offset_ms (valores negativos adelantan, positivos atrasan)
  • Asegúrate de que chunk_duration_sec sea consistente en todas partes
